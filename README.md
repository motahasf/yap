# What Is Yap?
**Yap** gives you **unique**, **memorable** phrases instead of numeric IDs with python

# Why/When Should I Use Yap?

Imagine your ID is:
```text
85926538
```
Your client will probably forget it instantly.
With **Yap**, you can replace that boring ID with something memorable:
> **"my grandpa played football yesterday."**
What happened? **Actually, nothing.**
Under the hood, Yap simply stores the mapping:
```text
85926538 → "my grandpa played football yesterday."
```
Now, instead of asking users to remember a random number, you give them a **unique, human-readable sentence** that is much easier to remember and share.
That's the idea behind **Yap**:
**turn boring IDs into memorable sentences.**

# Security Note 🔐

Yap is made for **public, non-sensitive stuff**.

Don't use your Yap as a password, secret key, or anything you wouldn't want an attacker to guess.

Why?

Because if your Yap is:

> **"my grandpa played football yesterday."**

an attacker might just think:

> *"Hmm... what if grandpa played football the day before?"* 🤔

So yeah — **Yap is memorable, not magical.** 🪄

Use it for public things like posts, products, links, and other data that isn't a big deal if someone discovers it.
